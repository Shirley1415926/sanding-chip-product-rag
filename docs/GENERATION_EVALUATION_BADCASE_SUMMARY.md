状态：本文件仅记录脱敏的评估结论，不包含原始模型回答、完整检索正文、API 配置或其他敏感信息。真实运行 trace、人工 review 和报告只保存在 gitignore 的 `data/runtime/generation_evaluation/`，不会提交。

## 已完成的来源绑定修复

此前的本地运行暴露过内部 `product_id` 泄露、无关 Top-K 来源展示，以及多商品比较误转人工等问题。来源绑定修复后，第二轮 DeepSeek 真实运行的来源正确性为 26/26，九道硬安全门题均未调用模型。该轮人工复核仍发现下列三个生成质量 badcase。

## 第三轮真实运行与离线口径校准

第三轮 DeepSeek 真实运行和规定人工复核已在本地完成：17 道可答题调用模型，九道硬安全门题均未调用模型；G11 与 G15 的自动检查通过。G13 的模型回答、来源和人工复核均通过，但旧版自动忠实度规则只扫描 Markdown 正文，漏算了模型实际收到的公开 `商品名称：古田竹荪干货`，因此把有依据的名称误报为无依据事实。

随后对该已完成父运行进行了纯离线的证据口径校准：以公开商品名称加 Markdown 正文作为同一份模型/评估证据，不包含 `product_id`、chunk ID 或检索分数。派生报告记录父 trace 的 SHA-256 并保留父运行不覆盖；校准结果为自动 26/26 通过，重算后的人工抽样 4/4 完成且通过。该结论只适用于固定商城目录、固定题集和已完成复核的限定范围，不代表正式商用就绪。

## 后续验证边界

本次结果不能证明英文询盘、真实用户表达、提示注入、长文档、大规模语料、并发、真实库存/履约/报价系统或长期资料更新后的表现。资料、模型或提示发生实质变化时，应重新执行真实运行和人工复核；不能把本次离线校准当成对未来模型行为的保证。
