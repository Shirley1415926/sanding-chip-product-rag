# 产品规格：叁鼎芯供应链商品知识助手

版本：0.1（第一阶段 MVP）
更新日期：2026-09-13

## 1. 产品目标

为叁鼎芯的采购客户、潜在供应商与经销商提供可追溯的商品知识问答。助手只依据已审核并导入的资料回答，将商品信息、合作规则与服务流程表达清楚；它不是交易系统、库存系统或报价系统。

## 2. 用户与问题范围

| 用户 | 可解决的问题 |
| --- | --- |
| 采购客户 | 型号参数、适用场景、包装、起订量、定制前置条件、已发布的售后流程 |
| 潜在供应商 | 入驻材料、审核步骤、质量与交付要求 |
| 潜在经销商 | 合作申请材料、区域与渠道规则、对接流程 |
| 客服/运营 | 用来源核查回答依据，并接住必须人工确认的问题 |

第一阶段只导入 Markdown；资料分为 `product`、`policy` 与 `faq` 三类。

## 3. 关键用户故事

1. 采购客户询问型号的已发布参数、标准包装与常规 MOQ，助手引用对应商品资料回答。
2. 采购客户询问定制，助手说明应提供的图纸、目标规格、预计数量与样品确认步骤，并引用规则资料。
3. 客户询问售后，助手依据 FAQ 说明资料准备和受理时限，不擅自认定责任或退款结果。
4. 供应商询问入驻，助手列出资料和审核流程。
5. 经销商询问合作，助手列出申请信息和对接步骤。
6. 客户询问当前库存、当天/实时交期、最终价格或最终报价时，助手不推测、不调用 LLM，固定引导人工确认。

## 4. 回答与安全规则

每个有知识依据的回答必须返回 `answer` 和 `sources`；每个来源至少包含 `source`、`product_id`、`document_type`、`updated_at`、`chunk_id`、`score`。

固定转人工文案：

> 抱歉，当前知识库没有足够的可核验依据。为避免提供不准确的库存、实时交期或最终报价，请转人工客服确认。

以下情况使用该文案：无命中文本、检索分数低于阈值、或问题要求库存/现货、实时或指定日期的交期、最终报价/具体价格。已发布的“参考周期”可以说明其非承诺性质，但不能写成实时交期承诺。

## 5. 本期验收标准

- 可摄取样例 Markdown，且每个 chunk 保留 `source`、`product_id`、`document_type`、`updated_at`。
- 商品、合作、售后类的十道代表性问题可检索到对应来源。
- 普通知识回答总会给出来源；风险问题与无依据问题固定转人工。
- 不实现在线下单、CRM 工单、库存查询、报价计算或资料审批。
