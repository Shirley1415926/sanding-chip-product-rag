# 产品规格：叁鼎芯供应链商品知识助手

版本：0.1（商城目录资料阶段）
更新日期：2026-09-13

## 1. 产品目标

为商城采购客户、潜在供应商与经销商提供可追溯的目录知识问答。助手只依据审核后导入的资料回答，返回来源和目录 URL；它不是交易、库存、报价、订单履约或审批系统。

v0.1 电子产品资料只是 RAG 技术链路的初始样例，已不属于当前商城知识库。当前版本的业务资料来自商城目录；资料未覆盖的信息一律转人工。

## 3. 用户与问题范围

| 用户 | 可依据资料回答的问题 | 必须转人工的问题 |
| --- | --- | --- |
| 采购客户 | 已公开产地、包装、展示价、规格、起订量、定制和明确写明的使用属性 | 库存、具体发货日期、订单级报价、批量价、经销价及未提供的商品事实 |
| 食品购买者 | 已公开产地、包装与规格 | 保质期、配料、过敏原及未提供的食品资料 |
| 潜在供应商 | 有供应商入驻入口 | 入驻材料和审批时间 |
| 潜在经销商 | 有经销商申请入口；批量采购可申请经销价与专属采购入口 | 实际经销价、批量价与未公开合作条件 |
| 客服/运营 | 用来源和来源 URL 核验回答依据 | 在知识库外补充事实或承诺 |

第一阶段只导入 Markdown；资料分为 `product`、`policy` 与 `faq` 三类。本批不保留旧电子产品 FAQ，也不虚构新的售后或食品 FAQ。

## 4. 回答与安全规则

每个有知识依据的回答必须返回 `answer` 和 `sources`；每个来源至少包含 `source`、`source_url`、`product_id`、`document_type`、`updated_at`、`chunk_id`、`score`。

固定转人工文案：

> 抱歉，当前知识库没有足够的可核验依据。为避免提供不准确的库存、实时交期或最终报价，请转人工客服确认。

以下情况使用该文案：无命中文本、检索分数低于阈值、库存/现货或“还能下单”、具体或实时交期/出库、订单级/批量/经销报价、未提供的食品保质期/配料/过敏原，以及问题中的明确属性没有出现在该商品资料中。未公开的定制范围、认证、材质、洗碗机适用性、食品安全信息和供应商/经销商准入规则同样转人工。公开展示价可以原样说明，但不能延伸为经销价、批量价或最终报价；陶瓷“微波炉适用”只可回答 玲珑瓷餐具套装。

## 5. 本期验收标准

- 每个 Markdown 文档与入库 chunk 保留 `source`、`source_url`、`product_id`、`document_type`、`updated_at`。
- 10 个商品和平台合作入口都可检索到对应来源，且不会用 A 商品资料回答 B 商品的明确属性问题。
- 普通知识回答总会给出来源和来源 URL；风险问题与资料缺口固定转人工。
- 不实现在线下单、CRM 工单、库存查询、报价计算、食品合规判断、资料审批或售后承诺。
