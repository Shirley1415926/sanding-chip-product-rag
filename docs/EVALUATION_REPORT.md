# 离线质量评估与风险控制报告

执行日期：2026-09-13

## 评估边界

本轮保留现有 `data/test_questions.json` 的 18 道回归验收题，未用它调节阈值。阈值选择只使用新增的 [holdout_evaluation_questions.json](../data/holdout_evaluation_questions.json)：共 **32 题**，覆盖同义改写、模糊选品、串商品属性、相近资料但结论不受支持、未公开商品/食品事实、绕开关键词的库存/交期/价格，以及平台公开入口与未公开准入规则。

执行命令：

```bash
.venv/bin/python scripts/run_offline_evaluation.py
```

评估使用 `BAAI/bge-small-zh-v1.5`、实际 Markdown 导入、切分、Chroma 和 Top-K。回答端注入 `ContextEchoLLM`，以便离线重复地验证检索证据和编排安全门；因此不代表接入真实生成模型后的文案质量。每个候选阈值的逐题记录已保存于 [EVALUATION_TRACES.json](EVALUATION_TRACES.json)，包含 query、硬安全门与原因、Top-K 来源/商品 ID/分数、最终 answer 或 handoff、预期与实际结果。

## 指标定义

- Source Hit@1 / Hit@3：仅在 17 道预期可答题中计算；原始 Top-K 的第 1 / 前 3 个 `product_id` 至少有一个属于该题预期集合。
- 错误回答率：全部 32 题中，预期转人工却回答，或预期可答却没有返回预期商品来源的比例。
- 正确转人工率：15 道预期转人工题中，实际转人工的比例。
- 可回答但被错误转人工的比例：17 道预期可答题中，实际转人工的比例。
- 串商品错误数：标记为串商品的题目中，实际仍然回答的数量。

## 失败案例与风险控制效果

当前 0.60 没有被评估集判为错误的最终回答。阈值候选 0.70 的失败用例表明过高阈值会损失召回：

| 题号 | Top-1 分数 | 0.70 的实际结果 | 说明 |
| --- | ---: | --- | --- |
| E03 | 0.6539 | 错误转人工 | 福建古田竹荪的同义规格/整箱问法 |
| E12 | 0.6264 | 错误转人工 | 模糊的“地方特产礼盒公开展示价”问法 |
| E14 | 0.6555 | 错误转人工 | “可用于微波炉的餐具套装”问法 |
| E16 | 0.6785 | 错误转人工 | 经销商申请入口的同义问法 |

本轮新增的控制包括：

- 对“还能下单”“出库”“买一箱能便宜多少”“拿货价”等绕开关键词的说法，在检索前硬转人工。
- 对供应商/经销商的资质、审核、区域、门槛等未公开准入规则，在检索前硬转人工；公开入口仍可回答。
- 对材质、骨瓷、洗碗机、认证、食品安全、定制范围/刻字/Logo、56 头等需字面证据的属性，在目标商品资料缺少对应文字时转人工。
- 对显式商品名，回答阶段只保留该商品的 chunk，防止把玲珑瓷的属性串给龙纹瓷盘等商品。

## 来源 URL 验证

10 份商品资料已将 `source_url` 改为 `https://txs.wyfdev.com/product/.../` 形式的公开详情页；平台合作资料使用 `https://txs.wyfdev.com/cooperation-apply/` 公开合作页。新增单元测试校验全部商品资料为 `https`、主机为 `txs.wyfdev.com`、路径以 `/product/` 开头，且合作资料使用公开合作页；不存在 `localhost:8081` 的用户可见来源。执行时逐一请求后，**10 个单品详情页和 1 个合作页均返回 HTTP 200**。

## 当前限制与下一步

- 32 题仍是小型离线保留集，不能替代真实会话分布、人工标注或长期线上监控。
- `ContextEchoLLM` 验证的是证据与安全编排；真实 LLM 仍须做独立的事实忠实度和提示注入测试。
- 当前“明确属性”保护使用保守词表，不是通用的字段级事实验证。新增商品资料时应同步补充字段化事实、反例与拒答题。
- 评分分布会随模型、商品数量和文本长度漂移；每次资料或 Embedding 模型显著变化后，应重跑保留集，再调整 `MIN_RELEVANCE`。
